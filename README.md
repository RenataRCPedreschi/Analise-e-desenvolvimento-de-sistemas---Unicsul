# Análise e Desenvolvimento de Sistemas 💻

Repositório dedicado aos projetos, atividades práticas e estudos desenvolvidos durante minha graduação em **Análise e Desenvolvimento de Sistemas**.

O objetivo é reunir minha evolução acadêmica, registrar os conhecimentos adquiridos e demonstrar a aplicação prática de conceitos de programação, desenvolvimento de software e tecnologia.

## 📚 Projetos e atividades

### 1. Algoritmos e Pensamento Computacional

Projetos desenvolvidos em **linguagem C**, com foco em lógica de programação, estruturas condicionais, laços de repetição, vetores e algoritmos de ordenação.

**Cálculo de IMC**

Sistema que calcula o Índice de Massa Corporal a partir do peso e da altura informados pelo usuário.

- Menu interativo e validação de entradas.
- Estruturas condicionais para classificação do IMC.
- Laço de repetição para navegação entre funcionalidades.

**Controle Semanal de Almoços**

Programa que registra a quantidade de almoços servidos durante sete dias.

- Armazenamento dos dados em vetor.
- Utilização de laços `for` para leitura e processamento.
- Cálculo do total semanal e da média diária.
- Apresentação formatada dos resultados.

**Ordenação de Pesos de Encomendas — Bubble Sort**

Sistema que organiza os pesos de dez encomendas utilizando o algoritmo Bubble Sort.

- Vetor de dez posições com valores simulados.
- Ordenação crescente e decrescente.
- Comparação e troca de elementos adjacentes.
- Preservação e exibição dos dados originais.

### 2. Desenvolvimento Front-End I

**Patas que Acolhem 🐾**

Projeto de site informativo voltado a uma organização fictícia de proteção animal, desenvolvido para aplicar conceitos de desenvolvimento web e acessibilidade.

O site apresenta informações sobre a organização, possibilidades de contribuição e um formulário demonstrativo de cadastro.

**Tecnologias utilizadas:**
- HTML5
- CSS3
- JavaScript

**Conceitos trabalhados:**
- Estruturação semântica de páginas.
- Estilização responsiva.
- Manipulação do DOM.
- Navegação entre páginas e comportamento SPA.
- Acessibilidade e experiência do usuário.

## 🛠️ Tecnologias e conhecimentos

- **Linguagens:** C e JavaScript.
- **Desenvolvimento web:** HTML5 e CSS3.
- **Fundamentos:** lógica de programação, algoritmos, estruturas de dados e programação estruturada.
- **Ferramentas:** Visual Studio Code, Git e GitHub.
